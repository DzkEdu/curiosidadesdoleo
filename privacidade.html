Política de Privacidade

Última atualização: 23 de novembro de 2026

Esta política explica como o aplicativo de publicação do Curiosidades do Léo ("aplicativo") trata dados. O aplicativo é de uso privado: ele só acessa as contas do próprio canal Curiosidades do Léo, autorizadas pelo dono do canal.

1. Uso dos Serviços de API do YouTube

O aplicativo usa os Serviços de API do YouTube (YouTube API Services) para enviar vídeos ao canal Curiosidades do Léo, agendar a publicação e ler estatísticas dos vídeos e do canal, como visualizações e inscritos. Ao usar o aplicativo, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google segue a Política de Privacidade do Google.

2. Outras plataformas

O aplicativo também usa a API Graph da Meta, para publicar Reels na Página do Facebook do canal, e a API de Publicação de Conteúdo do TikTok, para publicar vídeos na conta do canal. O tratamento de dados por essas empresas segue a Política de Privacidade da Meta e a Política de Privacidade do TikTok.

3. Quais dados são acessados

  • Tokens de acesso OAuth concedidos pelo dono do canal.
  • Identificadores do canal, da Página e da conta (ID e nome).
  • Estatísticas dos vídeos publicados pelo canal: visualizações, curtidas, comentários e número de seguidores ou inscritos.

O aplicativo não coleta dados de espectadores, não lê mensagens, não acessa contatos e não usa cookies de rastreamento. Este site não usa cookies nem ferramentas de análise.

4. Como os dados são usados

Os dados servem só para publicar os vídeos do canal nos horários programados e para mostrar ao dono do canal, num painel local, como os vídeos estão indo. Os dados não são vendidos, não são compartilhados com terceiros e não são usados para publicidade.

5. Armazenamento, retenção e exclusão

Tokens e estatísticas ficam guardados somente no computador do dono do canal, em arquivos locais que não são enviados a nenhum servidor nosso. Os tokens ficam guardados enquanto a autorização estiver ativa. As estatísticas obtidas pelos Serviços de API do YouTube são atualizadas ou apagadas em até 30 dias, como exigem as políticas do YouTube. As demais estatísticas são apagadas depois de 24 meses.

Exclusão de dados: para pedir a exclusão de qualquer dado, envie um e-mail para eduytfb@gmail.com. Os dados são apagados em até 30 dias. Revogar o acesso, como explicado abaixo, também bloqueia qualquer acesso novo na hora.

6. Como revogar o acesso

  • Google/YouTube: myaccount.google.com/connections ou a página de permissões de segurança do Google.
  • Facebook: Configurações › Integrações comerciais, em facebook.com/settings?tab=business_tools.
  • TikTok: no app, em Configurações e privacidade › Segurança › Gerenciar permissões de apps.
